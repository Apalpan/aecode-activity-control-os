# CODEX - AECODE Activity Control OS

## Regla central

Este repo es un tablero operativo interno. No es landing publica.

## Privacidad

- No publicar nombres personales.
- No publicar correos.
- No publicar links de WhatsApp, Zoom, Classroom, Miro o Drive.
- Usar `Persona 1`, `Persona 2`, `Equipo soporte`, `Agente #1`.
- Los links reales deben vivir solo en Google Sheets, Drive, GHL o backend protegido.

## Producto

El dashboard debe responder:

1. Que actividades estan activas.
2. Que falta para operar sin friccion.
3. Que se puede automatizar.
4. Que esta en riesgo.
5. Que accion debe ejecutarse ahora.

## North Star

Actividades academicas cerradas con evidencia operativa por semana.

## Criterio AECODE

El sistema debe conectar operacion con el loop educativo:

`inscrito -> acceso -> clase -> practica -> evidencia -> validacion -> certificado -> recompra`
